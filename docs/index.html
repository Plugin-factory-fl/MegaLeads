MegaLeadsAI — Privacy Policy

MegaMix AI, LLC (“we”, “us”) · Effective date: April 24, 2026
This policy describes the MegaLeadsAI Chrome extension and optional services you may configure with it.

1. What MegaLeadsAI is

MegaLeadsAI is a browser extension that helps you collect and organize publicly visible profile-related information from Instagram pages you choose to open (for example followers, following, or hashtag-related views), and display results in an in-browser dashboard for review and export. You decide when to run it and on which Instagram pages.

2. Data stored on your device

The extension uses Chrome’s local storage (for example chrome.storage.local) to keep product data on your machine, including items such as:

  • Lead rows and related session snapshots you generated;
  • UI preferences (for example theme, pacing, limits);
  • Run state so start/stop and progress work across tabs;
  • If you create an in-extension account: your account email and session metadata needed to sign you in;
  • Optional cached status for free-tier usage or subscription flags when you use server-connected features.

We do not use this local storage to track browsing on unrelated websites for advertising. Clearing extension data or uninstalling the extension removes locally stored extension data from your browser (subject to how Chrome manages extension storage).

3. Data sent to our servers (optional)

Some features only work if you (or your organization) configure the extension to talk to an HTTPS API you operate or authorize (for example a hosted “enrich” service, account registration, free-tier usage sync, Stripe checkout, or an assistant chat proxy). When those features are used, the extension may send:

  • A configured API key or bearer token (treat it as a secret; do not share your package publicly);
  • Lead fields and related text you submit for processing (for example usernames, bios, emails, phones, URLs you already collected);
  • Account email for features tied to your account (registration, subscription status, usage);
  • For optional AI flows: prompts and context you send to your configured service, which may be forwarded to a model provider under your configuration and policies.

If you do not configure remote services, the extension does not send the categories above to a developer-operated API. Distribution through the Chrome Web Store is subject to Google’s policies.

4. Instagram and third-party sites

When you use MegaLeadsAI on Instagram, your browser interacts with Meta / Instagram under your Instagram session and Meta’s terms. If you enable features that fetch public web pages (for example a link from a bio), those requests retrieve publicly available content you explicitly run through the tool; you are responsible for complying with applicable site terms and laws.

If you use Stripe for billing, payment flows are subject to Stripe’s privacy policy.

5. How we use information

We use information only to:

  • Provide, secure, and improve MegaLeadsAI;
  • Operate optional backend features you enable (enrichment, account registry, usage limits, billing);
  • Respond to support requests when you contact us.

We do not sell your personal information as a standalone product. We do not use your Instagram lead lists to run unrelated ad profiles on your behalf.

6. Retention

Data you keep in the extension remains until you delete it or uninstall. Server-side retention (if any) depends on how your configured API / database is operated; use retention settings and database practices appropriate for your organization and jurisdiction.

7. Security

Protect API keys and credentials. Use HTTPS endpoints. Restrict API keys to the minimum permissions needed. Anyone with physical access to your computer or an unpacked extension copy may be able to read values stored in the extension—treat packaged extensions like client-side software.

8. Children

MegaLeadsAI is not directed to children under 13 (or the minimum age required in your region). Do not use it to collect data from children.

9. Changes

We may update this policy from time to time. The “Effective date” at the top will change when we do. Continued use after updates means you accept the revised policy.

10. Contact

Questions about this policy or MegaLeadsAI: use the support contact shown on the Chrome Web Store listing for MegaLeadsAI, or email privacy@megaleadsai.com.
